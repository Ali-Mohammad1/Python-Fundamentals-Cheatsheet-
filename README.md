# Python Data Structures & Operations – Educational Script

This script provides a comprehensive, hands-on overview of fundamental Python concepts, including:

- Built-in keywords
- Numeric data types and operations
- String formatting (f-strings, precision, truncation, separators)
- Escape sequences and multi-line strings
- List operations (append, extend, sort, clear, copy, slice assignment)
- Tuple operations (concatenation, count, index, unpacking)
- Set operations (union, intersection, difference, symmetric difference, subset/superset checks)
- Dictionary operations (keys, values, get, update, setdefault, popitem, fromkeys)
- Boolean logic and type casting (bool(), logical operators)
- Type conversions (list, tuple, set, dict)

> **Note:** This code was written manually for learning purposes, then reviewed and formatted with the assistance of AI to improve readability and structure.
